# Third-party licenses

ToolsEnabled is licensed under the MIT License; that grant is made by
[`LICENSE`](LICENSE) and is not affected by anything in this file.

This file exists to satisfy the *other* direction: the components below are
redistributed inside the ToolsEnabled application payload, and their licenses require
that their copyright notices and license texts travel with the copies we hand out.
Reproducing them here is how that obligation is met, so this file ships with the
installer as well as living in the repository.

Each license body below is reproduced verbatim from the package as installed. This
file is generated from `node_modules`, not written by hand, so it cannot quietly drift
from what is actually shipped.

### Platform components

The desktop application is built on Electron, which is redistributed under the MIT
license, and embeds Chromium and its own dependencies. Electron's build tooling places
those notices beside the executable as `LICENSE.electron.txt` and
`LICENSES.chromium.html`; they are not duplicated here, because the copies shipped with
the binary are the authoritative ones.

### Not redistributed

`@ibm/telemetry-js` (Apache-2.0) appears in the dependency tree as a dependency of
`@carbon/colors`. It runs at install time in a development checkout and is not part of
the application payload, so no notice obligation arises for the distributed product. It
is named here rather than omitted, because a reader comparing this file against
`package-lock.json` would otherwise find a gap and have to guess what it meant.

### Compatibility

Every license above is Apache-2.0, OFL-1.1, ISC, BSD-3-Clause or 0BSD. Each of these
permits inclusion in a work distributed under the MIT License, so combining them with
the MIT grant on ToolsEnabled raises no license conflict. The obligations they do
impose are notice obligations, which is what this file discharges.

Two conditions are worth naming explicitly rather than leaving inside the wall of text
below, because they bind anyone who redistributes a modified build:

- **The fonts are under the SIL Open Font License 1.1**, which forbids selling the font
  files on their own and requires this notice to accompany every copy. A modified
  version of a font may not be distributed under its original reserved name.
- **Apache-2.0 components** require that recipients get a copy of the Apache license and
  that existing attribution notices are preserved.
